# Webby - Landing Page 🚀

A modern and responsive **Next.js** landing page built with **Tailwind CSS** for seamless performance and easy scalability.

🌐 **Live Demo:** [Webby Landing Page](https://webby-landing-page-plum.vercel.app/)  
📂 **GitHub Repository:** [nazmul162001/webby-landing-page](https://github.com/nazmul162001/webby-landing-page)

---

## 🚀 Features

✅ Fully responsive and mobile-friendly  
✅ Built with **Next.js 15** and **Tailwind CSS**  
✅ SEO-optimized for better search rankings  
✅ Fast performance with automatic code-splitting  
✅ Deployed seamlessly on **Vercel**
